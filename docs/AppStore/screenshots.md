# App Store screenshots — which captures, which sizes

Checked 27 November 2026 against Apple's App Store Connect
specifications page (via multiple trackers; see Sources). **Re-check
the page at submission time — Apple moved the required iPhone slot in
October 2026.**

## Required sizes (as checked)

| Device class (Apple's 2026 name) | Portrait pixels | Requirement |
| --- | --- | --- |
| iPhone with Dynamic Island (medium) — "6.3-inch" | 1206 × 2622 or 1179 × 2556 | **Required** for every iPhone app |
| iPhone with Dynamic Island (large) — "6.9-inch" | 1320 × 2868 / 1290 × 2796 / 1260 × 2736 | Optional (scales into the medium slot) |
| iPhone with Face ID (large) — "6.5-inch" | 1284 × 2778 / 1242 × 2688 | Optional; older pages still call it required when no 6.9-inch set exists |
| iPhone Duo | 1398 × 2034 (outer), 2007 × 2853 (inner) | Required from **April 2027** for iOS 27.1-SDK builds |

Rules: 1–10 screenshots per size; JPEG or PNG; **no alpha channel**;
the first 1–3 appear in search results. The app is iPhone-only (no
iPad set needed).
